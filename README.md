# Laravel Modeler Generator

Laravel Modeler Generator 是一款基于 Schema 驱动的 Laravel 代码生成器，专注于通过统一的数据模型定义，快速生成规范、可维护的 Laravel 基础代码。

推荐搭配 `laravel-modeler-studio` 可视化建模工具使用。

---

## ✨ Features

- Migration 生成
- Eloquent Model 生成
- PHP Enum 生成
- Factory / Seeder 生成
- Morph Map 生成
- 支持模块化目录结构
- Generated + Override 分层设计
- 可重复生成（Deterministic）
- 兼容 Laravel 12+
- 支持本地离线运行

---

## 🖥️ Requirements

- PHP 8.2+
- Laravel 12+
- Windows / macOS / Linux
